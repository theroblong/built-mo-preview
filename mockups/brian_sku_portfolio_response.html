✓ Yes — all three are answerable with the models already in the plan. No new model development required.
Question 1
Account readiness for incremental SKUs
Mo tracks cannibalization rates and velocity by retailer. For each account we can show: current BUILT SKU count, per-SKU velocity trend, and estimated net incrementality of adding one more SKU. The question answers itself — when the next SKU cannibalizes more than it grows, you've hit the ceiling at that account.
Question 2
Identifying over-SKU'd accounts
This is the same data sorted the other way. Accounts where per-SKU velocity is declining and inter-SKU cannibalization is elevated are the simplification candidates. Mo can rank these and surface the weakest SKU at each account as the pull candidate — a "get back to basics" priority list.
Question 3
Dreamwich: incremental distribution or trade-out bait?
The cannibalization model can score each account — is Dreamwich distribution likely to be incremental, or will it displace an existing SKU? For accounts that look over-SKU'd, Mo identifies the best trade-out target. The triage is actionable now from current portfolio health data.
Note on timing: This analysis is strongest once Dreamwich has a few weeks of sales history — pre-launch, we run the account triage on current SKU data, which already tells you which accounts are positioned for a clean incremental add vs. which need a swap.
