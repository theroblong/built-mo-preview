PART 1 Druid Ingest Rob

Rob ingests the SPINS CSV into the spins_full Druid datasource using the safe OVERWRITE WHERE pattern. This replaces only the segments covering the new date range — all historical segments remain untouched.

Critical: Do NOT use INSERT INTO (creates duplicate rows) or OVERWRITE ALL (times out at ~97M rows). Always use REPLACE INTO … OVERWRITE WHERE bounded to the new period only.
Pre-ingest baseline
Record current state before touching spins_full
Record current high-water mark date, row count per year, and distinct BUILT UPC count. If Brian's new file has a gap relative to current max date, stop and resolve with Brian before ingesting — a gap breaks all rolling-window features.
Ingest operation
REPLACE INTO spins_full OVERWRITE WHERE
Start the replacement window 1 week before current MAX to handle the boundary cleanly. Future bound must be explicit and DAY-aligned. Column names in Druid have commas stripped vs. CSV headers. Use Rob's original ingest spec.
Post-ingest QA gate (QS1 gate)
New UPCs must pass flavor-mapping review
Any BUILT UPC not yet in flavor_mapping blocks the Q-series. After ingest, run QS1 validation. New UPCs require curated flavor/pack entries before Q0 will process them correctly.
Post-ingest sanity checks
Verify counts and date range
Confirm row count delta matches expected new weeks, new high-water mark is correct, BUILT UPC count is ≥ pre-ingest count, and no weekly gaps exist in the new range.
PART 2 Druid Feature Engineering (Q-series) Jason

Druid SQL queries compress the 97M raw rows into governed intermediate tables. Each query has a defined input, a defined operation, and a named output table. The Q-series must run in order — later queries depend on earlier outputs.

Seed Tables QS1 · QS2 · QS3
Query Operation Data In Output Table
QS1Flavor mapping seed Map each BUILT UPC to curated brand line, flavor family, specific flavor, and pack count via inline CASE expressions. Re-run when product line changes. SPINS spins_full (BUILT rows only) flavor_mapping
QS2Flavor overrides seed Apply canonical overrides to resolve ambiguous or split flavor names when SPINS changes a flavor label mid-history. SPINS flavor_mapping flavor_canonical_overrides
QS3Item catalog seed Build item catalog with competitor tier assignments (Tier 1–3), category membership, and competitor eligibility flags for comparison pool generation. SPINS spins_full (all brands) item_catalog
